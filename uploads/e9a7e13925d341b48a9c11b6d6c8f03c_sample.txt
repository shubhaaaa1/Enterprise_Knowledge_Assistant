Enterprise RAG System Overview

This is an enterprise retrieval-augmented generation system built with FastAPI and ChromaDB.
It supports ingestion from GitHub repositories, Jira tickets, and uploaded documents.
The system uses Ollama with llama3 for local LLM inference, ensuring data stays on-premise.
Key features include role-based access control, citation highlighting, and conversational memory.
The retriever uses hybrid search combining semantic similarity and BM25 keyword matching.
Query rewriting improves recall by generating multiple query variants before retrieval.
All answers include grounding scores indicating how well the response is supported by retrieved content.
The citation engine maps every answer claim back to its source chunk with title, URL, and excerpt.
Sessions are stored in memory with a 60-minute inactivity timeout.
